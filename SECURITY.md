# Security

Only the most recent published release is maintained. Older releases and the
historical Node 18 / Alpine 3.17 images do not receive project updates.
Until the Node 24 upgrade is released, do not treat a historical image as a
supported replacement for the source in this checkout.

Report suspected vulnerabilities privately using GitHub's "Report a
vulnerability" action if available. If it is unavailable, open a public issue asking the
maintainer to arrange a private reporting channel, without including
vulnerability details. Do not post exploit details or credentials in public
issues.

Dependency update proposals require review, runtime verification, and a new
release. An upstream update or a green build does not imply an existing
published image has been patched.
